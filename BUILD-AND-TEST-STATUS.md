## Full production build

A full local Webpack build was not possible in the editing environment because its npm dependency directories were incomplete and external package downloads were unavailable. The repository includes a GitHub Actions workflow that performs:

1. `npm ci`
2. full TypeScript type-checking
3. analytics engine tests
4. production Webpack build
5. upload of `PluginZip.zip` as the artifact **CRNA-Performance-Analytics-v2.1.0**

The workflow runs automatically when this repository is pushed to the `main` branch. Do not treat the source ZIP as an installable RemNote plugin; install the `PluginZip.zip` generated by GitHub Actions.
