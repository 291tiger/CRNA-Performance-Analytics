# Update CRNA Performance Analytics to 2.1.0

1. Unzip this source package.
2. Replace the contents of the existing GitHub repository with these files. Keep the same repository and plugin ID.
3. Commit and push to the `main` branch.
4. Open **GitHub → Actions → Build RemNote Plugin**.
5. Open the newest successful run and download **CRNA-Performance-Analytics-v2.1.0**.
6. Unzip the GitHub artifact once. Install the enclosed `PluginZip.zip` in RemNote.

Do not upload this source ZIP directly to RemNote. GitHub Actions creates the installable plugin ZIP.
