# Changelog

## 2.0.0

- Added permanent sidebar access.
- Added queue-toolbar access during flashcard review.
- Added compact question analytics beside flashcard answer controls.
- Added saved review scope and exact current-card highlighting.
- Replaced raw-percent-only reporting with Mastery, Confidence, Coverage, Exam Readiness, and Trend.
- Added Bayesian adjustment for small samples.
- Added equal-card topic aggregation so heavily reviewed cards cannot hide unreviewed cards.
- Added exact-question filters for Again, repeat misses, Hard, volatile, unseen, overdue, and low-evidence cards.
- Added unique-card Again/Hard counts.
- Added card stability and transparent priority reasons.
- Added Study Next plans for 15 to 90 minutes.
- Added action items, today's data drivers, and per-scope score snapshots.
- Added weakness heat map, forgotten-topic ranking, lecture/topic drill-down, and Professor Lens safeguards.
- Added weekly and monthly progress views.
